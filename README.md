# SCP Terminal — Ретро ПК (Windows 98 внутри CRT)

Интерактивная «рабочая станция» старого ПК: толстый CRT-монитор, внутри — рабочий стол
Windows 98 с Проводником. В Проводнике только ваши проекты; клик по файлу открывает его
в окне по единому шаблону (пример — SCP-терминал с анимацией допуска).

## Быстрый старт (локально)
Откройте `index.html` в браузере (двойной клик). Для корректной загрузки картинок проектов
лучше поднять локальный сервер:
```
cd scp-desktop
python -m http.server 8000
# затем откройте http://localhost:8000
```

## 1. Оформление
Визуально это только «экран» старого ПК (рамка/фото монитора не используются), залитый
на фон комнаты. Эффекты «аналогового» экрана (сканлайны, блик, мерцание) — в style.css
(блоки `.crt-overlay` и `.glare`). Размер экрана — в `.monitor` (`width: min(1180px, 98vw)`).
Фото монитора не нужно.

## 2. Добавить проект
В `app.js` найдите массив `PROJECTS`. Скопируйте объект проекта и поменяйте:
- `id` — уникальный;
- `name` — имя файла в Проводнике;
- `tabs[].title` и `tabs[].html` — вкладки (любой HTML, картинки кладите в `assets/` и
  ссылайтесь `assets/имя.png`).
Тип `scp` даёт терминал с кнопкой «Подтвердить допуск» и последовательностью вкладок.

## 3. Опубликовать (GitHub Pages, ссылка работает у всех)
Один раз:
```
winget install GitHub.cli        # или скачайте gh с cli.github.com
gh auth login                    # откроется браузер — войдите в GitHub
```
Создать репозиторий и запушить:
```
git init
git add .
git commit -m "SCP Terminal"
gh repo create scp-desktop --public
git branch -M main
git push -u origin main
```
Включить Pages: в репозитории Settings → Pages → Source: `main` / root → Save.
Через минуту ссылка: `https://<ваш_логин>.github.io/scp-desktop/`
